Play The Last Witness

This is the studio's own WebAssembly export running inside the page. It is the same EV-044 case as the downloadable build, so progress made here stays on this device only.

Before you load it

  • It downloads about {{DEMO_BYTES}} of engine and game data the first time, then caches it.
  • It needs JavaScript, WebAssembly, WebGL 2 and a secure page (https, or localhost while developing).
  • The interface is a dense text terminal designed around a 1280×800 window. On a phone in portrait, read the game details or use the desktop build ({{DOWNLOAD_BYTES}}) instead.
  • The build is a demo: it has not had a first-time player test, and it reports itself as a debug export.

Loading is off until you press the button, so this page never spends your bandwidth without asking.

The demo runs in its own frame. Use the browser's own reload if it stops responding, or stop it above and load it again.
